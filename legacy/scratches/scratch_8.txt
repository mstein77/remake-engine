Normalerweise würden eine 300px pane von -1 .. 1 gehen
- Wenn wir über ein größere Pane mit 400px haben, dann
  wollen wir diese auf unserem Screen (mit 300px) sehen
  deswegen muss gelten 400 = 1 und wir müssen eine Pane
  mit 300px dann einen wert geben von 300/400 = +/-0.75

D.h. algorithmisch:
 1. suche größte dim "max" (die wir noch darstellen wollen)
 2. berechne die pane-dim über dim/max



 300x200 = 0.66 (300 * 0.66  = 200)

 0 .. 1 = 300   pixel-wertigkeit = 1/300
 0 .. 1 = 200                    = 1/200


 400x100 = 0.25

 0 .. 1 = 400 = 1/400
 0 .. 0.25 = 100 = 0.25/100

normX = 1/mX * dimX
normY = 1/(mY/mX) * dimY


 =>

 0 .. 0.75 = 300
 0 .. 0.75 * 0.66 => 0.495 = 200


screenWidth = (screen/2) - 1

planeWidth = (width/2) - 1 / screenWidth
