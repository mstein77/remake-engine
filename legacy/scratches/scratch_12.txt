 Entity-Change-Dependencies:
=====================================

 a) Tile-Index-Delete:
        In model.map:
           index wird durch 0 ersetzt, falls kein Nachrücker
        In model.tiles:
          <key> iwird gelöscht, falls kein Nachrücker
          index-prop wird 0, falls kein Nachrücker (alias)
        Durchlaufe frames in model.animations:
          frame-obj wird gelöscht, wenn id auf index ohne Nachrücker steht
        Durchlaufe tiles in model.brushes:
          index wird durch 0 ersetzt, falls kein Nachrücker

 b) Tile-Index-Safe-Delete:
        In model.map:
          Ersetze alle index, die größer sind als der gelöschte durch index-1
          wobei der gelöschte Index selbst durch 0 ersetzt wird
        In model.tiles:
          Angefangen beim vorletzten index der Folge-Indizes, werden die
          Props von index+1 auf diesen umkopiert. Der max-index wird gelöscht
          Ein index-prop auf den gelöschten index wird 0, alle Folge-Indices
          werden auf index-1 geändert
        Durchlaufe frames in model.animations:
          frame-obj wird gelöscht, wenn id auf dem gelöschten Index steht
          Andernfalls werden frame.id auf frame.id-1 gesetzt falls Folgeindex
        Durchlaufe tiles in model.brushes:
          Index wird durch 0 ersetzt, falls index dem gelöschtem entspricht
          Index wird index-1 falls Folgeindex

  - BUGFIX: animation delete => fehler im player



 c) Alias-Delete:
      In model.map:
         Ersetze das gelöschte Alias durch 0
      In model.tiles:
         Lösche <key> mit alias
      Durchlaufe tiles in model.brushes
         Ersetze das gelöschte Alias durch 0

 d) Alias-Rename:
      In model.map:
         Ersetze das gelöschte Alias durch das neue Alias
       In model.tiles:
         Kopiere <key> mit gelöschtem alias auf neues Alias um,
         anschliessend lösche den alten key
       Durchlaufe tiles in model.brushes
          Ersetze das gelöschte Alias durch das neue Alias


 e) Events-Delete:
      In model.events:
         Lösche den Event-Key
      In model.map:
         Lösche das gelöschte Event aus allen Event-Arrays

 f) Events-Rename:
      In model.events:
          Kopiere den Event-Key auf den neuen Key und lösche den alten
          anschliessend
      In model.map:
         Ersetze das gelöschte Event durch das neue in allen Event-Arrays




 g) Animation-Delete:
      In model.animation:
         Lösche den key der gelöschten animation
      In model.tiles:
         Lösche das animation-prop, wenn dieses der gelöschten animation
         entspricht

 h) Animation-Rename:
      In model.animation:
         Kopiere den key der gelöschten animation auf den neuen key um
         und Lösche den alten key anschliessend
      In model.tiles:
         Ersetze das animation-prop, wenn dieses der gelöschten animation
         entspricht durch das neue
