Cells:
 a) col
 b) index
 c) [index, event1, ..., eventN]

Writes:
 a) raw-write: value (ersetzt Zelle mit neuem Wert)
 b) index-write: value (ersetzt lediglich den index-Wert)
 c) event-overwrite: [event1, ..., eventN] (ersetzt die Events im Array)

Read:
 a) raw-read: gibt den kompletten Zellenwert zurück
 b) index-read: gibt nur den index-Wert der Zelle zurück
 c) event-read: gibt einen Event-Array zurück

ADD:
----------------
  DO:
    undoIndices = setIndicesFromObjects([{value, ...props},...], false);
  UNDO:
    deleteIndices(undoIndices)

INSERT:
----------------
  DO:
    undoIndices = setIndicesFromObjects(index, [{value, ...props}], false);
  UNDO:
    deleteIndices(undoIndices)

REPLACE:
----------------
    undoIndices = extractIndexFrom(replaceObjects);
    undoObjects = getObjectsFromIndices(undoIndices)
  DO:
    deleteIndices(undoIndices);
    setIndicesFromObjects(replaceObjects, true)
  UNDO:
    deleteIndices(undoIndices);
    setIndicesFromObjects(undoObjects, true)

CHANGE:
----------------
    changeProp = getChangeProp()
    undoValue = getIndexProp(changeProp)
  DO:
    setPropValue(index, changeProp, value)
  UNDO:
    setPropValue(index, changeProp, undoValue)

DELETE:
----------------
    undoObjects = getObjectsForIndices(indices)
  DO:
    deleteIndices(indices)
  UNDO:
    setIndicesFromObjects(undoObjects, false)
