---------------------------------------
 GRID-MODES:
---------------------------------------
 - display:

 - markerMove:


 - select:
     übernehme type + dim aus data in den cursor
     falls data.all dann setze Marker auf Grid-Dim, asonsten setze Marker zurück

     cursor:
       - left: setze marker auf currPos und starte
           markerMove (fixed || type=gap) oder markerResize

       markerMove:
         Exclusive Mode "marker-move":
         - autoScroll
         - mousemove + up

       markerResize:
         Exclusive Mode "marker-resize"
         - autoScroll
         - mousemove + up

       marker:
         - left:
             double => data.doubleClick
             markerMove | markerResize

   cleanUp: reset marker

 - pick:
     setze cursor auf rect 1x1

     cursor:
      - left:
          double => setMode("write")
          Setze selection auf cell aus cursorPos + cursorHighlight
          Exclusive Mode "pick"
          - up

      - right:
          Setze Bg-Selection auf cell aus cursorPos + cursorHighlight
          Exclusive Mode "pick-bg"
          - up

 - write:
     setze cursor aus aktuell selection-dim und berechne matrix
     starte neues Pfad-Object

     cursor:
      - left:
          trackWrite(true)

      - right:
          trackWrite(false)

     trackWrite(clear):
          autoScroll
          highlight = true;
          writeSelection(x, y);
          Exclusive Mode "write"
          - mouseMove:
              writeSelection(x, y); gridUpdate()
          - mouseUp:
              doAction(); gridUpdate(); highlight = false

 - add:
     setze cursor auf "rect" + dim=1x1

     cursor:
      - left:
          toggleCell(true)

      - right:
          toggleCell(false)

      toggleCell(add):
          Keine Zelle oder leere Zelle?
            Übernehme aktuelle GridZelle als Selection falls nicht leer
          Sonst:
            doValue über add oder sub bilden
            overwriteCell(x,y,doValue)
          Exclusive Mode "toggle"
            - up: highlight=false

 - drag:
     setzt cursor auf "rect" + dim=1x1

     cursor:
      - left:
          hole value aus aktueller cursorPos und merke diese und speichere als Selection
          autoScroll
          Exclusive Mode "drag":
           - up:
                falls EventRasterPos noch im Grid dann tausche downKoordinate mit aktueller
                Koordinate im Grid
                highlight=false
