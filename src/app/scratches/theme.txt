Aktueller Ablauf:

1.) CSS-Context

Holt sich bei jedem update, die computed styles aus den Konstanten im
document.body indem es über die type2props iteriert und anhand des typs
die values parsed.

Speichert diese dann im Context, zusammen mit:
  - update
      Ein Context-Update-Trigger

  - cssPropUpdate:
      Eine Ref auf eine Update-Methode, die auf einem übergebenen
      StyleObject ein CSS property auf einen value setzt

  - setStyles:
      Eine Methode welche alle (oder spezielle) Werte aus dem Context
      als Constanten auf einem Style-Object setzt

  - setStyleToValues
      Setzt die übergebenen key-values auf dem Style-Object anhand
      cssPropUpdate

2.) Window-Context

 Init:

   a) Erstellt das Theme aus dem Default-Theme und dem im Storage
   b) Extrahiert die hrefs aus den aktuellen Meta-Links und speichert diese
      im Array unter links.defaults der registry
   c) Setzt die Werte aus dem aktuellen Theme auf document.body.style
      (setStyleToValues)
   d) Setzt die Max-Dim-Werte aus der editorConfig auf document.body.style
   e) synchronisiert die Werte aus theme.linkResources über syncLinks

 Speichert die Werte aus dem theme und der editorConfig im Kontext, zudem:

   - syncLinks

   - cssPropUpdate (wird nur aus CssContext verlinkt)

   - isStyleLocked
       => LOCKED?

   - setStyleLock
       Setzt den übergebenen styleLock state:
         LOCKED   => übernimmt den übergebenen cssStyle und setzte die
                     linkResources aus dem theme in links.backups
         SAVED    => übernimmt den state
         UNLOCKED => Falls der letzte State SAVED und wenn ein cssStyle:
                        iteriere über key/values aus diesem und setze
                        diese auf dem document.body.style über cssPropUpdate
                     Ansonsten:
                        Update auf CssContext
                     Finally:
                        Lösche cssStyle und Backups

   - openSettings:
       Erstellt einen styleLock('LOCKED', cssRef.current.values)
       Öffne Settings-Modal

         cleanUp:
            styleLock('UNLOCKED')
            syncLinks(theme.linkResources)

         save:
            Speichert das Theme im Storage und in der Registry
            styleLock('SAVED');

3.) Modal

   if (wContext.isStyleLocked()) {
       modal umklammern mit <ThemeFreeze blockRef={trapRef} />
   }

4.) ThemeFreeze

   Erstellt einen neuen CssContext aus dem parent-Style aber biegt den
   setStyles so um, dass dieser auf dem parent arbeitet
   Setzt auf dem parent-context anschliessend blockRef.current.style
